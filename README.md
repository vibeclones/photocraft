# PhotoCraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [PhotoCraft](https://github.com/storytold/photocraft), by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/photocraft/latest/`
- Specific version: `/photocraft/v<version>/`, for example `/photocraft/v0.9.0/`

Each version folder is the unmodified contents of upstream's `photocraft-web-<version>.zip` release asset, with its license files. Upstream is dual-licensed Apache-2.0 / MIT; see `LICENSE-APACHE` and `LICENSE-MIT`.
